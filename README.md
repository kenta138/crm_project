## プロジェクト概要

営業担当者が取引先とのやり取りを記録・管理し、タスクの抜け漏れを防ぎ、日々の活動を効率的に日報化することを目的としたCRMです。

### 背景・課題

- 取引先ごとの接触履歴が属人化しやすく、フォロー漏れが発生しやすい
- 日報作成の手間を減らし、接触記録から自動で下書きを生成したい
- ロール（管理者・マネージャー・メンバー）によって閲覧・編集できる範囲を分けたい

### 解決すること

- 取引先・接触記録・タスクをCRMとして一元管理
- 最終接触日をもとに「要フォロー」対象を自動判定（判定基準は管理画面から変更可能）
- 接触記録をもとにAI（Gemini API）が日報を自動生成し、確認・編集した上で保存
- ロールベースのアクセス制御（Admin / Manager / Member）

## 主な機能

### 認証・アカウント
- ログイン／ログアウト
- 自己サインアップ（許可ドメイン制限＋管理者承認制）
- ロール別権限制御（Admin / Manager / Member）

### 取引先管理
- 取引先の登録・編集・削除（ソフトデリート）・一覧・詳細表示
- システムID（自動採番）と取引先管理ID（任意の編集可能なID、一意制約あり）の2種類のID管理、一覧での表示切り替え（設定はブラウザに保存）
- フェーズ・担当者・ラベル項目（複数選択）・最終接触日・要フォロー状態での絞り込み（折りたたみ表示）
- 会社名・担当者・フェーズ・最終接触日などでのクリックソート
- 最終接触日をもとにした「要フォロー」表示（判定日数は管理画面から変更可能）
- フェーズ別件数サマリー（折りたたみ表示）
- CSVインポート／エクスポート
- ラベルは「ラベル」と「項目」の2階層で管理し、項目はラベルごとにグループ化して表示・選択

### 接触記録管理
- 接触記録の登録・編集・削除・一覧・詳細表示
- 接触方法・期間・担当者・取引先での絞り込み
- 登録時に「記録のみ保存」「タスクも同時に保存」を選択可能

### タスク管理
- タスクの登録・編集・削除・一覧
- ステータス・期日・担当者での絞り込み
- 新規登録時、担当者は自分自身が初期値

### 日報（AI自動生成・非同期処理）
- ダッシュボードから対象日を選んでワンクリックで生成を開始（バックグラウンド処理のため、生成完了を待たずに他の操作が可能）
- 生成完了・失敗はページ遷移時に通知メッセージで確認可能
- 一覧画面で生成ステータス（生成中／完了／失敗）・生成日時・上書き（再生成）の有無を確認可能
- 閲覧範囲はロールに応じて変化（Member: 自分の日報のみ、Admin/Manager: 全員分）
- 編集は本人のみ可能
- AIへの指示プロンプトは管理画面から編集可能

### ダッシュボード
- ログインユーザー本人の期限超過・本日期限タスクを一覧表示（期限超過行はハイライト）、完了済みタスク一覧・新規タスク登録への導線あり
- 直近の自分の接触記録を表示し、詳細・取引先へすぐ遷移可能。新規接触記録登録・日報生成への導線あり

### 権限（ロール）
- Admin / Manager / Member の3ロールで、取引先・接触記録・タスクの編集/削除可否、ラベル管理・管理画面へのアクセス可否、日報の閲覧範囲などが異なります

### UI
- レスポンシブ対応（モバイル幅ではハンバーガーメニュー、テーブルは横スクロール）
- ヘッダーはスクロール時も上部に固定
- 新規登録・編集・削除ボタンの色分けを画面間で統一

### レスポンシブ対応
- モバイル幅ではナビゲーションがハンバーガーメニューに切り替わり
- テーブルは横スクロール対応

## 使用技術

| 分類 | 技術 |
|---|---|
| バックエンド | Python, Django 4.2.30 |
| データベース | PostgreSQL（本番）／ SQLite（ローカル開発） |
| 静的ファイル配信 | WhiteNoise |
| Webサーバー | Gunicorn |
| 環境変数管理 | python-decouple |
| デプロイ先 | Render |
| AI | Google Gemini API（google-genaiパッケージ、`gemini-3-flash-preview`モデル） |

## 外部API

- **Google Gemini API**（[Google AI Studio](https://aistudio.google.com/)で取得したAPIキーを使用）
  - 用途：接触記録をもとにした日報の自動生成
  - 使用モデル：`gemini-3-flash-preview`
  - 呼び出し箇所：`reports/views.py` の `report_generate`
